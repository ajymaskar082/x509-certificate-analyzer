# X.509 Certificate Analyzer

## Жобаның мақсаты

Бұл жоба X.509 цифрлық сертификаттарын талдауға арналған. Бағдарлама PEM форматындағы сертификатты оқып, оның негізгі ақпараттарын көрсетеді.

## Қолданылатын технологиялар

- Java 25
- Apache Maven
- JUnit 5
- Java Security API (`CertificateFactory`, `X509Certificate`)

## Негізгі мүмкіндіктері

- Сертификат иесін анықтау (Subject).
- Сертификатты шығарған ұйымды көрсету (Issuer).
- Сертификаттың жарамдылық басталу және аяқталу мерзімдерін көрсету.
- Қолданылған алгоритмді анықтау.
- Қате немесе жарамсыз файл жолын өңдеу.

## Орнату

1. Репозиторийді GitHub-тан жүктеп алыңыз.
2. Жобаны IntelliJ IDEA бағдарламасында ашыңыз.
3. JDK және Maven баптауларын тексеріңіз.
4. Maven арқылы жобаны құрастырыңыз:

```bash
mvn clean package
```

## Қолдану

Бағдарламаны IntelliJ IDEA арқылы `Main` класынан іске қосыңыз. Іске қосу параметріне сертификат файлының жолын беріңіз.

Мысалы:

```text
certificate.pem
```

Бағдарлама сертификаттың Subject, Issuer, жарамдылық мерзімі және алгоритмі туралы ақпаратты көрсетеді.

## Тестілеу

Тесттерді іске қосу үшін:

```bash
mvn test
```

JUnit 5 тесттері сертификат талдау класының негізгі әрекеттерін тексереді.

## Қауіпсіздік туралы ескерту

Жоба Java-ның стандартты Security API құралдарын пайдаланады. Жеке кілттерді, құпия деректерді және нақты пайдаланушылардың сертификаттарын GitHub репозиторийіне жүктемеңіз.

Сертификат туралы ақпаратты оқу оның сенімді екенін немесе электрондық қолтаңбаның жарамдылығын өздігінен дәлелдемейді.

## Қолдану мысалы

Терминал арқылы сертификат файлын талдауға болады:

```bash
mvn clean package
java -cp target/classes kz.edu.cybersecurity.Main certificate.pem
```

Мұндағы `certificate.pem` — талданатын X.509 сертификатының PEM форматындағы файлы.

## Тестілеу

Жоба JUnit 5 көмегімен тексеріледі. Тесттерді іске қосу үшін:

```bash
mvn test
```

Тесттер сертификат файлын оқу, файлдың бар-жоғын тексеру және қате файлдарды өңдеу жағдайларын қамтиды.

## Қауіпсіздік ескертуі

Бағдарлама сертификаттың негізгі ақпаратын көрсетеді. Сертификаттың жарамдылық мерзімін көрсету оның сенімді екенін немесе цифрлық қолтаңбасы дұрыс екенін толық дәлелдемейді. Сертификаттың сенімділігін жеке тексеру қажет.
